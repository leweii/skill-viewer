Skill Viewer

View and summarize Claude Code skills on GitHub with AI-powered summaries using Gemini, OpenAI, or Claude.

Install from Chrome Web Store View on GitHub

Features

🔍

Auto-Detection

Automatically finds Claude Code skills in .claude/skills/ or skills/ directories when browsing GitHub.

🤖

AI Summaries

Get concise 2-3 sentence summaries explaining what each skill does, powered by your choice of LLM.

🌐

8 Languages

Full UI and summary support for English, Chinese, Japanese, Korean, Spanish, French, and German.

👁

Draggable Sidebar

Resize the sidebar width from 250px to 600px. Your preference is saved automatically.

🌙

Dark Mode

Seamlessly matches your system preference or GitHub's dark theme.

🔒

Privacy First

No data collection. API keys stored locally. Only communicates with GitHub and your chosen LLM.
